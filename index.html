Налаштування

Місце та погода

GPS не потрібен: координати можна ввести вручну або знайти за назвою (Open-Meteo Geocoding).

Повітряна тривога

Токен безкоштовно видається на сайті alerts.in.ua (форма «API request»). Без токена тривоги не відображаються — картка буде сірою.

Відключення світла

Офіційного відкритого API графіків для застосунку немає, тому графік вводиться вручну з офіційного сайту/повідомлень обленерго. Формат: інтервали ГГ:ХХ-ГГ:ХХ через кому, напр. 06:00-10:00, 18:00-22:00. Порожньо = відключень немає. Якщо інтервал переходить через північ — розділіть його на два дні (до 24:00 і з 00:00).
