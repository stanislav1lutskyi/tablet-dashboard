# Домашнє табло (Smart Home Dashboard)

Легкий вебзастосунок (HTML + CSS + JavaScript, без бібліотек) для старого Android-планшета в горизонтальній орієнтації:
годинник, погода, повітряна тривога та графік відключень світла на одному екрані.

## Структура

| Файл | Призначення |
|---|---|
| `index.html` | Розмітка: головний екран і сторінка налаштувань |
| `style.css` | Темна тема, картки, масштабування в `rem` |
| `app.js` | Уся логіка: годинник, погода, тривоги, графік, налаштування, звук |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA: офлайн-кеш застосунку, встановлення, повний екран |
| `server.py`, `start-windows.bat` | Локальний сервер для Windows (+ проксі для тривог) |

Усі налаштування й кеш даних зберігаються в `localStorage` пристрою.

## Джерела даних — що працює «з коробки», а що ні

| Блок | Джерело | Потрібно від вас |
|---|---|---|
| Час | Системний час, показується в часовому поясі Europe/Kyiv | нічого |
| Погода | Open-Meteo (безкоштовно, без ключа) | обрати населений пункт у ⚙ (за замовчуванням Івано-Франківськ) |
| Тривога | API alerts.in.ua (`/v1/alerts/active.json`) | **безкоштовний токен**: форма «API request» на сайті alerts.in.ua; вставити в ⚙ |
| Світло | Офіційного відкритого API графіків (зокрема Прикарпаттяобленерго) для застосунку я не знайшов, тому графіки **не вигадуються** | ввести вручну в ⚙ **або** вказати URL власного JSON |

**Без токена картка тривоги сіра** («Немає даних») — вигаданий статус ніколи не показується. Якщо зв'язок зник, а востаннє була тривога, табло залишає червоний стан із приміткою про можливу застарілість (щоб не показати «все гаразд» помилково).

### Ручне введення графіка світла (⚙ → «Відключення світла»)
- Формат: `06:00-10:00, 18:00-22:00` (через кому). Порожньо = відключень немає.
- **Шаблон** діє щодня; для «Сьогодні»/«Завтра» можна задати окремі інтервали (режим «Задати вручну»). Минулі дні видаляються автоматично.
- Інтервал через північ розбийте на два: `22:00-24:00` (сьогодні) і `00:00-02:00` (завтра).
- Колонка «Можливе відключення» малюється жовтим.
- Групу (наприклад `4.1`) і назву оператора введіть у цій же секції.

### Власне джерело графіка (необов'язково)
Якщо у вас є свій JSON (наприклад, його генерує ваш скрипт), вкажіть його URL. Формат:
```json
{ "days": { "2026-11-16": { "off": ["06:00-10:00"], "maybe": ["18:00-20:00"] },
            "2026-11-17": { "off": [], "maybe": [] } } }
```
або з кількома групами: `{ "groups": { "4.1": { "days": { … } } } }`. Ручні значення «Сьогодні/Завтра» мають пріоритет над джерелом, джерело — над шаблоном. Сервер повинен дозволяти CORS.

### ⚠ Важливо про CORS для тривог
Браузер може заблокувати запит до `api.alerts.in.ua`, якщо сервіс не повертає CORS-заголовки. Я **не зміг перевірити це наживо** (із моєї тестової середовища немає доступу до цих API), тому код перевірено на змоканих відповідях. Якщо після введення токена картка лишається сірою з повідомленням про блокування — використайте проксі:
- Якщо табло відкрито з `server.py` (див. нижче), у ⚙ → «Адреса API» вкажіть `http://<IP-комп'ютера>:8080/proxy/alerts` (адреса друкується при запуску сервера).
- Або розгорніть крихітний проксі (наприклад, Cloudflare Worker), що додає `Access-Control-Allow-Origin: *`, і вкажіть його адресу там само.

## Запуск на Windows
1. Встановіть Python 3 (python.org, під час встановлення поставте «Add python.exe to PATH»).
2. Розпакуйте архів, двічі клацніть **`start-windows.bat`**.
3. Відкрийте `http://localhost:8080` у Chrome/Edge. Натисніть ⚙, введіть токен, групу, графік → «Зберегти».
4. Для перевірки з планшета (той самий Wi-Fi) відкрийте адресу з рядка «З планшета» у вікні сервера. Якщо не відкривається — дозвольте Python у брандмауері Windows.

(Можна й без Python: відкрийте `index.html` двічі клацанням — годинник і ручний графік працюватимуть, але Service Worker і запити можуть бути обмежені.)

## Встановлення на Android-планшет
Планшету потрібен постійний доступ до застосунку. Є два варіанти:

**A. Хостинг (рекомендовано для 24/7, не потрібен увімкнений ПК).** Завантажте папку на безкоштовний HTTPS-хостинг статичних сайтів (GitHub Pages, Cloudflare Pages, Netlify). На планшеті відкрийте адресу в Chrome → меню ⋮ → **«Установити застосунок»** / «Додати на головний екран». Service Worker і PWA працюють лише через HTTPS (або `localhost`). Для тривог на хостингу може знадобитися CORS-проксі (див. вище).

**B. Через ПК у домашній мережі.** Запустіть `server.py`, відкрийте на планшеті `http://<IP-ПК>:8080` у Chrome → «Додати на головний екран». Через `http` по IP офлайн-кеш Service Worker недоступний (це обмеження браузера), а ПК має бути завжди ввімкнений.

## Постійний повноекранний режим 24/7
1. Встановлений PWA вже відкривається без адресного рядка (manifest: `fullscreen`, альбомна орієнтація). Додатково кнопка ⛶ у нижньому рядку вмикає повний екран.
2. **Екран не гасне:** Налаштування Android → Екран → «Режим очікування» максимально; у «Для розробників» увімкніть **«Не вимикати екран» (Stay awake)** при зарядці. Застосунок додатково просить Wake Lock, якщо браузер його підтримує (Chrome 84+).
3. Для справжнього «кіоску» (блокування виходу, автозапуск після перезавантаження) надійніше за все працює безкоштовний режим у Fully Kiosk Browser: Start URL = адреса табло, увімкнути Keep Screen On, Launch on Boot, Kiosk Mode.
4. Планшет тримайте на зарядці; яскравість — у системних налаштуваннях. У ⚙ є програмне «нічне затемнення» (воно автоматично вимикається під час тривоги).
5. Щодня о 04:00 табло саме перезавантажується, щоб не накопичувати пам'ять.
6. Звук у браузерах вмикається лише після дотику до екрана: поки його не було, внизу з'являється підказка «Торкніться екрана». Після перезавантаження пристрою один раз торкніться екрана.

## Поведінка при помилках
- Немає інтернету: годинник і графік (ручний) працюють; погода показує збережені дані з позначкою часу; тривога стає сірою (див. вище); внизу «Інтернет: Немає зв'язку».
- Кожен запит має тайм-аут; помилка одного блоку не зупиняє інші.
- Кнопка ⟳ оновлює все негайно; також оновлення відбувається при поверненні зв'язку.

## Що перевірено, а що ні
Перевірено в headless Chrome (1280×800 і 1024×600) на змокованих відповідях API: рендер усіх блоків, стани тривоги (зелений/червоний/район/сірий), стан «світла немає», валідація й збереження налаштувань, 12/24 год, приховування блоків, відсутність помилок у консолі, відсутність прокрутки. **Не перевірено:** реальні відповіді Open-Meteo/alerts.in.ua, CORS alerts.in.ua, звук, робота на конкретному старому планшеті. Структуру відповіді alerts.in.ua (`alerts[].location_oblast`, `location_type`, `alert_type`, `started_at`) взято з публічних клієнтських бібліотек — якщо сервіс змінить формат, потрібна правка функції `parseAlerts` в `app.js`.

⚠ Табло — лише інформаційне доповнення й **не замінює** офіційні сповіщення про небезпеку.
